# KaleCancer

## The question

How can clinical features and pathology patch features be combined to explore time-to-event prediction? KaleCancer's refactor snapshot supplies a small synthetic example that trains an **intermediate-fusion Cox model**.

## Your route

1. [Getting started](getting-started.md): Set up the refactor checkout and run the example.
2. [Hands-on activity](hands-on.md): Locate the synthetic inputs and identify the prediction task.
3. [Results and interpretation](results.md): Understand the output and limits of a synthetic survival exercise.

> [!NOTE]
> No real patient data are needed for this starter exercise. For a real-data extension, the repository also includes **HANCOCK** examples; those require separate dataset access and additional setup.
