# Jupyter notebooks

The [Cancer Live-Coding Notebook](MDAS/cancer/cancer_live_coding.ipynb) is available in `notebooks/MDAS/cancer/`, alongside its `synthetic_data_generation.py` helper. View it on GitHub or open it in a Jupyter-compatible editor.

[Open in Google Colab](https://colab.research.google.com/github/pykale/mmai-mdas/blob/main/notebooks/MDAS/cancer/cancer_live_coding.ipynb).

Colab opens the notebook, but dependencies and the companion Python module need additional setup. Keep the helper available in the notebook's execution directory and review its relative data paths. Confirm the compatible session environment before running it.

No Cardiac session notebook is currently available; use the [Cardiac tutorial](../tutorials/kalecardiac/getting-started.md).

> [!CAUTION]
> Synthetic results are not clinical evidence. Do not upload identifiable patient data, confidential material or private datasets to public services or this repository.
