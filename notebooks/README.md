# Jupyter notebooks

The [Cancer Live-Coding Notebook](MDAS/cancer/classification.ipynb) is available in `notebooks/MDAS/cancer/`, alongside its `synthetic_data_generation.py` helper. View it on GitHub or open it in a Jupyter-compatible editor.

[Open in Google Colab](https://colab.research.google.com/github/pykale/mdas/blob/main/notebooks/MDAS/cancer/classification.ipynb).

Colab opens the notebook, but dependencies and the companion Python module need additional setup. Keep the helper available in the notebook's execution directory and review its relative data paths. Confirm the compatible session environment before running it.

The Cardiac tutorial notebooks, [CardioVAE](MDAS/cardiac/tutorial-CardioVAE.ipynb) and [LS-EMVAE](MDAS/cardiac/tutorial-LSEMVAE.ipynb), are in `notebooks/MDAS/cardiac/` with their `configs/` folder. See the [Cardiac tutorial](../tutorials/kalecardiac/getting-started.md) to choose and run one.

> [!CAUTION]
> Synthetic results are not clinical evidence. Do not upload identifiable patient data, confidential material or private datasets to public services or this repository.
