# Resources

## Official project repositories

- [PyKale](https://github.com/pykale/pykale): the underlying machine learning library.
- [KaleCancer](https://github.com/pykale/cancer): cancer analysis workflows; these tutorials use the `cancer-refactor` development snapshot.
- [KaleCardiac](https://github.com/pykale/cardiac): cardiac analysis workflows; these tutorials use the `cardiac-main` development snapshot.

The public default branches may differ from the development snapshots used by the tutorials. Confirm the session revisions and how to access them with the organisers before setup.

## Technical references

The following paths are relative to the corresponding software repository root.

**KaleCancer (`cancer-refactor`):** `README.md`, `docs/quickstart.md`, `examples/synthetic/synthetic_survival.py`, and `examples/hancock/`.

**KaleCardiac (`cardiac-main`):** `README.md`, `docs/quickstart.md`, `examples/README.md`, `examples/cardiovae_multimodal/README.md`, and `examples/lsemvae_ecg/README.md`.

For KaleCancer environment management, see the [uv documentation](https://docs.astral.sh/uv/). Follow the [KaleCancer setup](../tutorials/kalecancer/getting-started.md) or [KaleCardiac setup](../tutorials/kalecardiac/getting-started.md) for your chosen track.

## Help and follow-up

For library questions, use [PyKale discussions](https://github.com/pykale/pykale/discussions) or the relevant repository's issue tracker. Session-specific support arrangements are still to be confirmed.

Real-data HANCOCK examples require separate dataset access and additional setup. Discuss permissions, privacy and compute requirements with the organisers before using your own clinical data.
