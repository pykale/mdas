# Resources

## Project repositories

- [PyKale](https://github.com/pykale/pykale)
- [KaleCancer](https://github.com/pykale/cancer): session material based on the user-supplied `cancer-refactor` ZIP, not necessarily the public default branch.

These URLs were recovered from PDF link annotations and their public repository pages verified on 22 October 2026. This verifies repository availability, not equivalence to the development snapshots or command compatibility.
